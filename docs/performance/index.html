How to read these numbers

What ran

Both CLI workloads used the standard password profile. The repeated-data run used 1,000 files of 4 KiB each; the random-data run used eight 10 MiB files. Every restored path and SHA-256 digest was checked, then a batch was deleted in one rewrite and the remaining entries were verified.

What to keep in mind

Repeated data compresses unusually well. Storage, cache state, CPU load, and operating system affect timing. These measurements use disposable synthetic files and are not a performance guarantee.
